Time Complexity (Singly Linked List)

Operation Time Space Description
Insert Beginning O(1) O(1) Updates HEAD pointer directly
Insert End O(n) O(1) Traverses to the last node
Insert Position O(n) O(1) Traverses to position - 1
Delete Beginning O(1) O(1) Frees first node, shifts HEAD
Delete End O(n) O(1) Traverses to second-to-last node
Delete Position O(n) O(1) Traverses to node before target
Search Element O(n) O(1) Linear traversal from HEAD
Reverse List O(n) O(1) In-place pointer reversal (iterative)
